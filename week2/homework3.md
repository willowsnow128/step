## 問題
次の操作をほぼ O(1) で実現するデータ構造を考える
* 与えられた <URL, Web ページ> があるかないかを検索
* もしない場合、キャッシュ内で一番古い <URL, Web ページ> を捨てて、代わりに与えられた <URL, Web ページ> を追加する


## 回答
### 追加・削除をO(1)で行う方法
単方向リストを用いると、途中のデータを切り離そうとする時に、その1つ前のデータのつながりを付け替える必要があり、前には戻れないため、リストの先頭から再度1つ前のデータを探し直すことになり、O(N)の時間がかかってしまう。そのため、常に自分の前と後ろを把握しておける双方向リストを用いて、自分の前後のデータ同士を繋ぎ直すことで、O(1)でリストから切り離すことができる。追加をする際も現在の先頭と双方向に繋ぐことでO(1)で繋ぐことができる。

### 検索をO(1)で行う方法
ハッシュテーブルを使って検索することでO(1)にすることができる。
具体的にはキーにurlを入れて、値を双方向リスト内の該当データへの行き先にすることでスムーズにアクセスできる。
