## 問題
次の操作をほぼ O(1) で実現するデータ構造を考える
* 与えられた <URL, Web ページ> があるかないかを検索
* もしない場合、キャッシュ内で一番古い <URL, Web ページ> を捨てて、代わりに与えられた <URL, Web ページ> を追加する


## 回答
### 一番古いデータをO(1)で見つけて削除・追加する方法
データの新しさの順番を管理するために、双方向リストを用いる。
データをアクセスされた順に繋ぎ、リストの先頭を「一番新しいデータ」、末尾を「一番古いデータ」として管理する。これにより、キャッシュが一杯になった際、リストの末尾を見るだけで捨てるべき一番古いデータをでO(1)で探して削除できる。
また、リストの途中のデータを更新して先頭に移動させたり、古いものを切り離したりする際も、双方向リストであれば常に前後の繋がりを把握しているため、リンクを付け替えるだけで削除も追加もO(1)で行うことができる。

### 検索をO(1)で行う方法
与えられた URL がキャッシュに存在するかどうかは、ハッシュテーブルを用いてO(1)で検索する。
具体的には、キーに「URL」、値に「双方向リスト内の該当データへの直接のリンク」を保存する。これにより、データの有無を一瞬で確認できると同時に、双方向リスト内の場所も特定できるため、探す手間がかからない。
